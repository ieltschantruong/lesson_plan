Reading Section

Strategy Guide & Vocabulary

🎯 Strategy: Matching Headings

  • 1. Read the headings FIRST to get the main ideas.
  • 2. Skim the first and last sentence of each paragraph.
  • 3. Look for synonyms, NOT exact words.
  • 4. Beware of "distractor" headings that only cover a minor detail in a paragraph.

✅ Strategy: Multiple Choice (Many Answers)

  • 1. Highlight keywords in the question stem.
  • 2. Scan the passage to locate the relevant section (answers are usually clustered).
  • 3. Eliminate clearly wrong options based on the text.
  • 4. Cross-reference remaining options with the text carefully.

🎯 Strategy: Listening Section 2 & Maps

Section 2 Overview

  • • Usually a monologue (one person speaking).
  • • Topic is set in an everyday, social context (e.g., a speech about local facilities).

Multiple Choice (1 Answer) & Maps

  • • Read ahead: Identify the core difference between options A, B, C.
  • • Maps: Find the starting point (e.g., "You are here"). Follow directional language (north, south, next to, opposite).
